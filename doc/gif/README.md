## Media rules

Enforced by CI, and required for any addition here:

- Original captures produced from this simulator.
- No individuals, office interiors, or unreleased products.
- No identifying EXIF metadata (GPS, serial, author, artist).
- Keep files small enough that the README stays usable; re-encode rather than
  committing a multi-megabyte capture when a shorter loop makes the same point.
